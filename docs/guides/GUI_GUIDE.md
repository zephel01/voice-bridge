# GUI ガイド

Voice Bridge の GUI では、すべての設定をドロップダウンで簡単に変更できます。このガイドでは各設定項目を説明します。

## 起動方法

GUI モードで起動するには、以下のコマンドを実行します：

```bash
# 翻訳モード（デフォルト）
python main.py

# チャットモード
python main.py --mode chat --vad
```

## 設定項目

### 入力デバイス

マイクまたはシステム音声をキャプチャするループバックデバイスを選択します。

- **翻訳モード：** BlackHole（macOS）、Loopback デバイス（Windows）、Monitor of ...（Linux）を選択
- **チャットモード：** マイクデバイスを選択

> 利用可能なデバイスを確認するには：
> ```bash
> python main.py --list-devices
> ```

### 声（TTS エンジン）

音声合成に使うエンジンとキャラクターを選択します。

| エンジン | 対応言語 | キャラクター例 |
|---|---|---|
| VOICEVOX | 日本語 | ずんだもん、四国めたぼ 等 |
| CoeiroInk | 日本語 | リリンちゃん 等 |
| Edge TTS | 多言語 | 各国言語のナレーター |

### 会話言語

翻訳モード時のソース・ターゲット言語、またはチャットモード時の言語を選択します。

**対応言語：** 英語 / 日本語 / 中国語 / スペイン語 / フランス語 / ドイツ語 / 韓国語

> **Moonshine エンジン使用時：** en / ja / zh / es / ko のみ対応（fr, de は未対応）

### モード

アプリケーションのモードを切り替えます。

| モード | 説明 |
|---|---|
| `translate` | リアルタイム音声翻訳 |
| `chat` | ローカル LLM との音声会話 |

### ASR（音声認識エンジン）

音声をテキストに変換するエンジンを選択します。

| エンジン | 日本語精度 | 英語精度 | 速度 | 用途 |
|---|---|---|---|---|
| Whisper（small） | 高 | 高 | 普通 | 日本語チャット・翻訳全般 |
| Whisper（medium） | 最高 | 最高 | 遅い | 高精度が必要な場合 |
| Moonshine | 低 | 高 | 最速 | 英語チャット・英語翻訳 |

### VAD（音声アクティビティ検出）

Silero VAD による自然な発話検出を有効にします。チャットモードで推奨です。

| 設定 | 説明 |
|---|---|
| 有効 | 発話終了を 0.8 秒で自動検出（自然な会話） |
| 無効 | RMS ベースで検出（レスポンス遅延が増加） |

### LLM（チャットモード）

ローカル LLM サーバーの利用可能なモデルを選択します。

起動時に自動で検出されます（Ollama サーバーが起動している場合）。

> **モデル選択の目安：**
> - 日本語精度：`gemma-2-9b-it` > `qwen2.5-14b` > `qwen2.5-7b`
> - 処理速度：`qwen2.5-7b` > `gemma-2-9b-it` > `qwen2.5-14b`
> - メモリ使用量：`qwen2.5-7b`（~5GB） < `gemma-2-9b-it`（~7GB） < `qwen2.5-14b`（~10GB）

詳しくは [Ollama セットアップガイド](../setup/OLLAMA_SETUP.md) をご覧ください。

## デモ

チャットモードでの実際の動作例：

```
あなた: こんにちは
   AI: こんにちは！どうぞ、何でもお手伝いします。
       （VOICEVOX:ずんだもん で読み上げ）
       遅延: 0.9s（初回音声 0.4s）
```

## 設定の反映

設定を変更したら「開始」ボタンを押すと、新しい設定が反映されます。

チャットモードではテキスト入力欄も表示され、キーボードからもテキストを送信できます。
